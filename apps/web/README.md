# apps/web

The user-facing web application: a React + TypeScript single-page app built with Vite. This is where the typing surface, results screens, settings, and all user-visible UI live. Product truth: `docs/spec/master-spec-v1.md` (read on demand). Non-negotiables from `AGENTS.md` apply most strongly here (no setState per keystroke; the typing surface is sacred; WCAG 2.2 AA).
